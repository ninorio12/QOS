Feedback sur les actions utilisateur

Quand tu cliques sur un bouton (sauvegarder, supprimer, envoyer...), comment tu veux être informé ?

A

Toast en bas à droite

Un petit bandeau apparaît brièvement en bas de l'écran. "Sauvegardé ✓" ou "Erreur ✗". Disparaît après 3 secondes. Déjà en place sur Contacts/Pipeline.

✓ Devis envoyé avec succès
B

Feedback inline sur le bouton

Le bouton lui-même change d'état : spinner pendant le chargement, puis ✓ vert ou ✗ rouge. Très discret, ne perturbe pas la lecture.

⟳ Envoi...
✓ Envoyé
✗ Erreur
C

Les deux — Recommended ✦

Spinner inline pendant l'action + toast de confirmation à la fin. Le spinner dit "ça tourne", le toast confirme "c'est fait". Couverture maximale.

⟳ Sauvegarde...
→ 1 sec →
✓ Sauvegardé
