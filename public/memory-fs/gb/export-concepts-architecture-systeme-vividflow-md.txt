# Architecture système VividFlow

## Principe

VividFlow fonctionne avec cinq couches :

1. **Telegram** — direction privée : DM Jonathan, DM Thomas, groupe direction à 3.
2. **Slack** — exécution agentique : agents producteurs.
3. **Data OS** — vérité visible : tâches, clients, décisions, statuts, approvals, logs.
4. **Second Brain** — mémoire lisible : doctrine, décisions, process, offres, apprentissages.
5. **GBrain** — mémoire active : graph, recherche, scopes, context loader.

## Règle

Les humains parlent normalement. Le système filtre, route, exécute et mémorise sans friction.
