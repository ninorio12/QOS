# Process — Setup multi-bots Slack Hermes

## Règle principale

```text
1 profil Hermes = 1 fichier .env = 1 bot Slack
```

## Profils

- `chief_of_staff` = COO, Telegram + Slack.
- `cmo_executor` = Slack-only.
- `csm_executor` = Slack-only.
- `operations_executor` = Slack-only.
- `rd_executor` = Slack-only, visible comme Data Analyst Executor.

## Variables executor

```text
SLACK_BOT_TOKEN=xoxb-...
SLACK_APP_TOKEN=xapp-...
SLACK_ALLOWED_USERS=U0B7FK89Z5G,U0B7G67LM1T
SLACK_ALLOW_BOTS=mentions
```

## Variables Telegram interdites sur executors

```text
TELEGRAM_BOT_TOKEN
TELEGRAM_ALLOWED_USERS
TELEGRAM_HOME_CHANNEL
TELEGRAM_HOME_CHANNEL_NAME
TELEGRAM_FALLBACK_IPS
TELEGRAM_WEBHOOK_URL
TELEGRAM_WEBHOOK_PORT
TELEGRAM_WEBHOOK_SECRET
```

## Troubleshooting

- `No LLM provider configured` → configurer/copier l'auth LLM du profil COO.
- `Telegram bot token already in use` → l'executor a hérité de Telegram, le rendre Slack-only.
- Mention non cliquable → utiliser `<@U...>`.
- Bot-to-bot ignoré → ajouter `SLACK_ALLOW_BOTS=mentions`.
- `Unauthorized user: U0B7G67LM1T` → ajouter le COO dans `SLACK_ALLOWED_USERS`.
