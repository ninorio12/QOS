## assistant — 2026-06-12T11:48:11.039866

Parce que **les tokens sont bien configurés côté Hermes**, mais ça ne veut pas forcément dire que les apps sont visibles dans Slack. Les causes probables : 1. **Les apps ne sont pas réinstallées après changement** - Si tu as modifié nom, scopes, App Home ou Event Subscriptions, il faut faire : `OAuth & Permissions` → **Reinstall to Workspace** 2. **App Home / Messages Tab désactivé** - Si désactivé, Slack affiche parfois : “l’envoi de messages vers cette application a été désactivé”. - À activer dans chaque app : `App Home` → `Messages Tab`. 3. **Les bots ne sont pas invités dans les channels** - Une app peut être installée mais invisible dans un channel tant qu’elle n’est pas invitée. - Il faut faire `/invite @nom_du_bot` dans le channel. 4. **Tu regardes la sidebar Slack, pas la liste des apps** - Slack n’affiche pas toujours les apps dans la sidebar automatiquement. - Il faut chercher dans `Apps` ou via la barre de recherche. 5. **L’app existe côté Slack Developer mais pas installée dans le workspace** - Être créée sur `api.slack.com/apps` ≠ visible/utilisable dans Slack. - Il faut installation workspace + bot token actif. De mon côté, j’ai vérifié : les 5 profils ont bien `SLACK_APP_TOKEN` et `SLACK_BOT_TOKEN`. Donc le souci est presque sûrement côté Slack UI/install : **réinstaller chaque app + activer App Home + inviter les bots dans les channels.**
