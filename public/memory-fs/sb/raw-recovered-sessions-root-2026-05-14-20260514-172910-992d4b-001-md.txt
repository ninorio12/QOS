Un **topic Telegram** c’est surtout un **canal de discussion séparé**.

- son propre prompt système

ou mieux :

# 10. Question importante : API Server ou intégrer AIAgent en librairie ?

Hermes peut être utilisé de deux façons.

## Option A — Appeler Hermes API Server

C’est le plus safe au début.

```txt
VividFlow API → Hermes API Server
```

Avantages :
- contrat HTTP clair
- compatible OpenAI
- streaming déjà prévu
- moins de coupling avec le code Python interne

Inconvénient :
- moins de contrôle profond

## Option B — Importer `AIAgent` directement

Possible côté Python :

```python
from run_agent import AIAgent

agent = AIAgent(
 model="...",
 enabled_toolsets=["web", "memory"],
 session_id="...",
)
response = agent.chat("...")
```

Avantage :
- contrôle maximal

Inconvénients :
- API interne mouvante
- état global/env compliqué
- dangereux en multi-tenant si même process
- plus dur à scaler proprement

Recommandation : **API Server d’abord**, worker custom plus tard si nécessaire.

# 11. Le point sécurité majeur

Le plus gros risque vu dans GitHub/Reddit : **l’agent ne doit jamais voir les vrais secrets**.

Mauvais :

```env
GITHUB_TOKEN=...
STRIPE_SECRET=...
SUPABASE_SERVICE_KEY=...
```

dans le container agent.

Bon :

```txt
Agent → demande action
Credential Proxy → injecte secret côté host
API externe → réponse
```

Donc :

- secrets chiffrés côté SaaS
- proxy de credentials
- tokens courts
- scopes précis
- audit complet
- jamais de secrets bruts dans le prompt, logs, env agent
