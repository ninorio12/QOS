# Hermes Chat — accès email personnel

## Décision
Hermes Chat CLI et le bot Telegram Chief of Staff doivent appliquer la même règle pour l’email personnel de Thomas.

## Règle d’usage
- L’email personnel de Thomas est un contact privé, utilisable uniquement si Thomas demande explicitement un envoi ou un test vers son email perso.
- Ne jamais utiliser cet email comme expéditeur VividFlow.
- Les emails VividFlow doivent partir de la boîte agent VividFlow via le compte Himalaya `vividflow` avec l’expéditeur visible **Équipe VividFlow**.
- Ne pas utiliser le token Gmail API OAuth utilisateur pour envoyer des emails VividFlow.

## Conséquence opérationnelle
Quand Thomas demande un envoi vers son email perso :
1. Composer l’email avec destinataire perso.
2. Envoyer via `himalaya template send --account vividflow`.
3. Vérifier la sortie `Message successfully sent!`.
4. Supprimer tout fichier temporaire `.eml` contenant l’adresse.

## Confidentialité
Ne pas réafficher l’adresse email en clair dans les réponses, logs résumés ou notes partagées.
