### 5. Agents IA

**Titre** 
Des agents IA conçus pour le travail réel

**Format** 
Chaque agent doit avoir :
- prénom
- rôle
- description courte
- “Ce qu’il peut faire”
- bullets immersifs, sans ponctuation finale

#### Amani — Agent commercial
Aide vos équipes à suivre les prospects, prioriser les opportunités et préparer les prochaines actions commerciales.

Ce qu’il peut faire :
- repérer les prospects les plus avancés dans votre pipeline
- préparer une relance adaptée au contexte de chaque échange
- résumer les conversations pour que l’équipe sache quoi faire ensuite
- signaler les opportunités qui risquent de refroidir

#### Mei — Agent support client
Trie les demandes, répond aux questions simples et remonte les sujets importants à vos équipes.

Ce qu’elle peut faire :
- répondre aux questions fréquentes à partir de vos informations internes
- identifier les demandes urgentes avant qu’elles ne s’accumulent
- transmettre les sujets sensibles à la bonne personne
- garder l’historique des échanges pour éviter les répétitions

#### Akira — Agent analyse
Transforme vos données, documents et conversations en informations claires pour décider plus vite.

Ce qu’il peut faire :
- analyser vos documents pour en extraire les informations importantes
- détecter les tendances dans vos conversations, ventes ou opérations
- transformer des données dispersées en synthèses exploitables
- préparer des rapports simples pour vos décisions importantes

#### Nia — Agent administratif
Automatise les tâches répétitives, structure les informations et garde vos dossiers à jour.

Ce qu’elle peut faire :
- classer automatiquement les documents dans les bons dossiers
- extraire les informations clés depuis vos formulaires ou fichiers
- préparer les documents récurrents à partir de vos modèles
- garder vos informations internes propres et faciles à retrouver

#### Sora — Agent contenu
Aide à créer, recycler et organiser vos contenus pour vos réseaux, emails et supports commerciaux.

Ce qu’elle peut faire :
- transformer une idée brute en contenu prêt à travailler
- recycler vos contenus longs en posts, emails ou scripts courts
- organiser un calendrier éditorial autour de vos priorités
- adapter vos messages selon le canal et l’audience

#### Imani — Agent relance
Suit les prospects, clients ou dossiers jusqu’à la prochaine action importante.

Ce qu’elle peut faire :
- détecter les conversations qui attendent une réponse
- préparer les relances au bon moment selon le contexte
- rappeler les actions importantes avant qu’elles ne soient oubliées
- maintenir le lien avec vos prospects, clients ou partenaires

#### Kenzo — Agent opérations
Coordonne les tâches, les outils et les suivis pour éviter les pertes d’information entre vos équipes.

Ce qu’il peut faire :
- transformer une demande entrante en tâche suivie
- synchroniser les informations entre vos outils métier
- alerter l’équipe quand une action bloque un processus
- garder une vue claire sur ce qui avance, ce qui attend et ce qui bloque

#### Aya — Agent RH / onboarding
Aide à structurer le recrutement, l’intégration et le suivi des collaborateurs.

Ce qu’elle peut faire :
- résumer les profils candidats pour préparer la sélection
- organiser les étapes d’onboarding des nouveaux collaborateurs
- préparer les messages, documents et rappels internes
- suivre les premières étapes d’intégration pour ne rien laisser au hasard

#### Mino — Agent d’exécution
Transforme les décisions validées en actions concrètes.

Ce qu’il peut faire :
- envoyer les relances validées au bon moment
- créer les tâches dans vos outils après une décision
- mettre à jour vos fiches clients, dossiers ou pipelines
- déclencher les workflows nécessaires après validation humaine
