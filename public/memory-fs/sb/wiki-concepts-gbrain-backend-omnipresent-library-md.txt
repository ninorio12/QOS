# GBrain backend omniprésent

GBrain n’est pas prioritairement un bot Slack visible.

GBrain est la bibliothèque omniprésente de VividFlow : mémoire durable, règles, décisions, apprentissages, liens de contexte et restitution.

## Architecture validée

- Telegram : cockpit décision.
- Slack : surface d’exécution agents.
- COO / Chief of Staff : Orchestrateur Qualité, visible Telegram + Slack, délègue et récupère les sorties.
- Agents Slack : CMO, CSM, Ops/QA, R&D exécutent chacun leur métier.
- GBrain / Second Brain : backend mémoire et contexte, utilisé par COO et agents.

## Règle

Les agents ne doivent pas attendre qu’un humain demande “mets ça dans GBrain”.
Chaque sortie substantielle doit qualifier automatiquement :

- preuve / source ;
- utilité VividFlow ;
- risque / incertitude ;
- routage : GBrain, Data OS, R&D ou bruit.

## GBrain vs bot Slack

Un bot Slack GBrain est optionnel.
La priorité est que GBrain nourrisse tous les agents et le COO en arrière-plan.
