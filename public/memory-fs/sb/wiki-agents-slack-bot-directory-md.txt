## Convention

Pour déclencher un bot depuis un autre bot Slack, utiliser le format ID Slack :

```text
<@U...>
```

Pas le display name texte.

## Interdits

- Ne plus utiliser `CSM Executor`.
- Ne plus utiliser `Operations Executor`.
- Ne plus utiliser `Data Analyst Executor`.

## Règle mention native — 2026-06-15
Source : `raw/messages/20260615-163404_telegram-session_e06b8e98.md`.

Sur Slack, le Coordinateur doit mentionner les agents avec les vrais IDs natifs `<@U...>` pour obtenir une mention bleue et déclencher les bots. Les chaînes texte de type `@agent_...` ne sont pas fiables.

Les IDs déjà vérifiés restent la source de vérité de cette page. Ne pas inventer les IDs manquants : les récupérer via configuration/profils Slack avant usage.
