## 2. Architecture saine à implémenter

- **Convex** = source de vérité, jobs, résultats, UI.

- **Providers externes** = seulement quand nécessaire.

Structure logique :

## 3. Ordre d’exécution recommandé

**Étape 1 — YouTube proprement**
- API key serveur.
- Récupérer :
 - channel info
 - dernières vidéos
 - Shorts si détectables
 - stats vidéo
 - publishedAt
- Upsert idempotent dans Convex.
- Pas de transcript au début sauf fallback déjà prêt.

**Étape 2 — Orchestration adaptative**
- Chaque creator a :
 - `lastCheckedAt`
 - `lastPostAt`
 - `postingFrequency`
 - `nextCheckAt`
 - `platform`
 - `status`
- Le cron ne scanne que les créateurs `nextCheckAt <= now`.
- Si pas actif : fréquence réduite.
- Si actif : fréquence augmentée.

**Étape 3 — Instagram**
- Ne pas faire un gros scrape permanent.
- D’abord lightweight check.
- Full scrape seulement si nouveau post/reel/carousel détecté.
- À isoler hors Convex, dans worker Hermès.

**Étape 4 — TikTok**
- Pas maison en premier.
- Provider low-cost type Scrapfly ou équivalent.
- Cadence basse : 1-2 fois/jour.
- Anti-bot TikTok = piège à temps.

## Ce qu’on construit
