# R1 VividFlow — narrative deck

## Décision validée
Le deck R1 VividFlow reste une structure **7 pages**, pas 4 pages.

Structure cible :
1. Miroir
2. Friction
3. Nécessité d’un système
4. Corps vivant / système agentique
5. Mémoire métier
6. Ce que ça libère
7. Situation réelle / démo

Les pages 1–3 remplacent l’ancien début. L’ancienne page 7 devient la nouvelle page 4.

## Correction d’angle
Ne plus répéter “gagner du temps” sur plusieurs pages.

Le nouvel axe narratif :

```text
charge invisible → continuité → chaîne tenue
```

Phrase-pont validable :

```text
Ce n’est pas le temps qu’il faut optimiser. C’est la continuité du travail.
```

## Pages 1–3 — calibrage opérationnel

### Page 1 — Miroir
- Émotion : reconnaissance immédiate.
- Effet attendu : “oui, c’est exactement mon quotidien.”
- Message : une demande simple peut mobiliser toute une organisation.
- Copy candidate : `Ce n’est jamais juste une demande.`
- Visuel : scène métier éditoriale réelle, routine dense mais lisible.

### Page 2 — Friction
- Émotion : tension / fatigue lucide.
- Effet attendu : “c’est là que ça se complique.”
- Message : le problème n’est pas la demande, c’est tout ce qu’elle déclenche.
- Copy candidate : `Derrière chaque demande, il y a tout un travail à faire avancer.`
- Visuel : mêmes objets/univers, mais désalignés; validations en attente, relances, informations manquantes; accent orange sur le point de blocage.

### Page 3 — Nécessité d’un système
- Émotion : prise de conscience.
- Effet attendu : “ce n’est pas un problème d’outil, c’est un problème de continuité.”
- Message : il faut tenir la chaîne, pas seulement traiter une tâche.
- Copy candidate : `Le problème, c’est que personne ne tient toute la chaîne.`
- Rôle : préparer la page 4 “corps vivant / système agentique” sans vendre VividFlow trop tôt.

### Copy sequence à tester
Version prioritaire :
1. `Ce n’est jamais juste une demande.`
2. `Derrière chaque demande, il y a tout un travail à faire avancer.`
3. `Le problème, c’est que personne ne tient toute la chaîne.`

Alternative plus sobre :
1. `Une demande arrive. Et toute l’organisation se met en mouvement.`
2. `Le vrai travail commence après la demande.`
3. `Ce qu’il faut tenir, ce n’est pas une tâche. C’est la chaîne.`

## Direction visuelle
Direction validée à tester : **réel éditorial opérationnel bold**.

Formule :

```text
photographie éditoriale bold + situation métier réelle + surcharge visible + phrase très simple + interfaces/outils autour
```

Version objet/technologie :

```text
objets réels du travail + interfaces projetées/intégrées + mise en page éditoriale premium
```

Version humaine, si utilisée : incarner physiquement la charge invisible avec une expression/mise en scène forte, sans meme ni caricature du dirigeant.

Règles :
- fond crème / off-white ;
- grande typo noire ;
- accent orange très contrôlé ;
- objets métier concrets : téléphone, message client, devis, laptop, CRM card, dossier, validation, relance ;
- chaque objet doit servir une vraie scène métier ;
- pas d’objet décoratif.

À garder :
- éditorial premium ;
- réel / tangible ;
- tension opérationnelle ;
- identité Gen Z sérieuse mais pas corporate morte.

À éviter :
- dashboard SaaS générique ;
- IA futuriste / néon / chatbot ;
- poster Pinterest rétro ;
- design lab Gen Z décoratif ;
- humour gratuit, meme, ridicule ;
- pauvre patron caricaturé.

## Méthode de décision créative
Ne pas décider d’abord “humain / objet / dashboard”.

Pour chaque page, décider dans cet ordre :
1. émotion à transmettre ;
2. message à retenir ;
3. souvenir à créer ;
4. tension visuelle ;
5. forme graphique la plus juste.

Un humain peut apparaître au maximum sur une page si cela sert un moment fort : surcharge, passage de relais, contrôle retrouvé ou solitude du dirigeant face au système. Ce n’est pas un gimmick.
## Micro-copy validée — bas de slide
Pour remplacer un texte de bas de page jugé plat, formulation recommandée :

```text
Le dirigeant décide. Le système fait avancer le travail.
```

Alternatives acceptables si la slide demande une nuance plus douce :
- `Vous gardez la décision. Le système garde le mouvement.`
- `Vous choisissez la direction. Les agents font avancer la journée.`

Règle : privilégier une phrase courte qui oppose clairement **décision humaine** et **mouvement opérationnel du système**, sans repartir sur “gain de temps”.
## Page 6 — Vision / bascule R2

Rôle : après la présentation de l’agentique, faire basculer vers la vision et préparer le R2, sans cours technique.

Phrase recommandée :

```text
L’agentique ne remplace pas votre entreprise. Elle entre dans son fonctionnement.
```

Sous-phrase possible :

```text
Elle relie vos outils, vos équipes et vos informations pour que le travail avance avec plus de continuité.
```

CTA R2 :

```text
Voyons où l’agentique peut entrer dans votre entreprise.
```

Bouton : `Préparer le R2`.

Variante plus patron / boomer :

```text
L’IA ne doit pas rester à côté du travail. Elle doit entrer là où le travail se fait.
```
