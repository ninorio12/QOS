## Ce que ça change dans ma façon de coder

Je ne coderai pas des features “one-shot client”. 
Je coderai avec ces règles :

- chaque donnée a un `workspaceId` ;
- chaque action vérifie le tenant ;
- chaque agent appartient à un workspace ;
- chaque intégration est branchée par workspace ;
- chaque usage doit pouvoir être mesuré ;
- chaque feature doit marcher pour 1 client comme pour 100.

## Règle produit à garder

Si une feature nécessite une installation manuelle lourde par client, elle n’est pas MVP.

abonnement → workspace → conversations → CRM → agent → valeur
