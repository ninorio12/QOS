# VividFlow Second Brain — Schema

## Domain
Mémoire opérationnelle VividFlow : stratégie, agents, décisions, process, offres, clients, Data OS, Slack/Telegram, doctrine business.

## Règles
- `raw/` = sources brutes immuables. Ne jamais modifier.
- `wiki/` = synthèse propre maintenue par agent.
- Toute décision structurante doit être listée dans `wiki/index.md` et `log.md`.
- Pas de secrets, tokens, IP privée, credentials ou messages privés sensibles non validés.
- Telegram privé reste privé par défaut ; seuls les signaux validés entrent ici.
- Data OS = vérité visible des tâches/statuts/clients.
- Second Brain = mémoire lisible/doctrine/process/décisions.
- GBrain = moteur mémoire actif/scopes/context loader quand branché.

## Seuils
Créer/mettre à jour une page quand :
- décision validée ;
- règle business stable ;
- process réutilisable ;
- architecture système ;
- rôle agent ;
- output important.

Ne pas capturer : bruit, “ok”, brouillons non validés, secrets, conversations privées sans validation.
