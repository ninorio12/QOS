# Process — Délégation Telegram → COO → Slack Executor

## Flux cible

```text
Telegram Jonathan/Thomas
→ COO comprend et cadre
→ COO poste dans Slack avec mention interne <@U...>
→ Executor produit
→ COO synthétise / valide / renvoie Telegram
→ Data OS est mis à jour si action réelle
```

## Préconditions techniques executors

```text
SLACK_ALLOW_BOTS=mentions
SLACK_ALLOWED_USERS=U0B7FK89Z5G,U0B7G67LM1T
```

## Règles

- Telegram privé ne se déverse jamais automatiquement dans Slack.
- Le COO donne un brief court : mission, contexte, livrable, contrainte.
- Slack sert de journal visible et d'atelier.
- Data OS reste la source de vérité des actions.
