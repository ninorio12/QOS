# VividFlow Second Brain Schema

## Règle
- `raw/` = sources immuables, append-only.
- `wiki/` = synthèse durable seulement.
- `ops/` = état technique du Second Brain.
- `outputs/` = livrables produits.

## Taxonomie
- agents
- processes
- concepts
- decisions

## Frontmatter minimum
```yaml
type: agent|process|concept|decision
status: active|draft|archived
updated: YYYY-MM-DD
sources: []
```
