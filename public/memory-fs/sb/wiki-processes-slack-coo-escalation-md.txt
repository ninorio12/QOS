# Escalade COO Slack

Règle : les agents spécialistes peuvent mentionner le COO quand une validation qualité est nécessaire.

Handle exact COO : `<@U0B7G67LM1T>`

Cas où mentionner COO :

- livrable final prêt à valider ;
- doute qualité ;
- blocage ;
- risque client/business ;
- besoin de décision humaine ;
- asset généré à récupérer/valider/livrer à Telegram.

Cas où ne pas mentionner COO :

- bruit ;
- statut intermédiaire non utile ;
- étape triviale ;
- réponse qui peut être corrigée directement par l’agent.

Format attendu :

```text
<@U0B7G67LM1T> COO check — [livrable/blocage] — [validation demandée]
```

Le COO ne copie-colle pas : il audite, challenge, corrige ou renvoie à l’agent si nécessaire. Il remonte seulement le final validé ou le blocage à Telegram.
