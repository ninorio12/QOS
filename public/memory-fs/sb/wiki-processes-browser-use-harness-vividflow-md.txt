# Browser Use / Browser Harness — VividFlow

## Règle

La clé Hermes ne remplace pas une clé Browser Use Cloud. Pour Browser Use Cloud, utiliser une clé dédiée `BROWSER_USE_API_KEY` dans le `.env` du profil Hermes concerné.

## Usage

- Browser Use : production scraping/enrichissement récurrent, sessions/profils, pages dynamiques, sorties structurées.
- Browser Harness : debug visuel, QA, inspection DOM, screenshots, clics précis quand Browser Use bloque.

## Configuration profil Hermes

1. Identifier le profil actif et son `.env`.
2. Ajouter la clé Browser Use dans le `.env` du profil, sans la recopier dans le wiki.
3. Activer les tools utiles du profil : browser, terminal, file, web.
4. Redémarrer le gateway/service du profil.
5. Tester depuis le profil réel avant de l’utiliser dans un cron ou un agent Slack.

## Garde-fou

Ne pas mettre une clé Browser Use dans le global si le bot tourne avec un profil séparé. Ne jamais exposer la valeur de clé dans Slack, Telegram, raw curé ou wiki.
