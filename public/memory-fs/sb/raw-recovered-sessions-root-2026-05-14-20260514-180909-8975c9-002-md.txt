## 1. UX / motion design avec Cursor

Cursor peut très bien coder de la belle UX, mais **il ne l’invente pas toujours bien seul**.

Le bon setup :

```txt
v0 / Figma / screenshots inspiration
→ Cursor
→ code React/Tailwind
→ Framer Motion
→ test navigateur
→ itérations visuelles
```

Pour un SaaS premium, je partirais sur :

- **Tailwind**
- **shadcn/ui**
- **Framer Motion / Motion**
- **Lenis** si besoin de scroll premium
- **Radix UI** pour accessibilité
- **React Hook Form + Zod** pour forms
- **Sonner** pour toasts
- **Recharts / Tremor** pour dashboards

## Niveau motion à viser

Pas des animations gadget. 
Un SaaS doit avoir des micro-interactions propres :

- page fade + slide léger
- skeleton loaders
- streaming response fluide
- hover cards subtils
- drawers/modals smooth
- drag & drop propre
- loading state instantané
- toast feedback
- transitions 200–300ms
- respect `prefers-reduced-motion`

Exemple :

```txt
Click → feedback immédiat
Loading → skeleton
Success → toast + optimistic UI
Erreur → message clair
Long task agent → timeline / progress / “agent is working”
```

Ça donne une app qui “respire” et qui paraît pro.
