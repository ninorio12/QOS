# Slack Agentic Workspace VividFlow

## Rôle de Slack

Slack est l'atelier d'exécution VividFlow, pas le cockpit privé.

- Telegram = bureau privé / direction / demandes sensibles.
- COO = filtre, arbitre, priorise, délègue.
- Slack = espace visible de production et coordination.
- Data OS = source de vérité pour tâches, leads, clients, statuts.
- Second Brain = bibliothèque lisible.
- GBrain = futur bibliothécaire/context loader.

## Channels recommandés

- `#direction` : Jonathan, Thomas, COO. Arbitrages et décisions.
- `#ops-cockpit` : coordination opérationnelle, dispatch, blocages.
- `#content-growth` : contenus, hooks, carousels, campagnes.
- `#client-success` : leads, clients, relances, paiements, pipeline.
- `#delivery-ops` : SOP, QA, delivery, checklists, process.
- `#rd-watch` : veille IA, scraping, tendances, opportunités.

## Règle de bruit

Les executors ne doivent pas répondre partout automatiquement.
Ils répondent quand ils sont mentionnés ou délégués.
