## Solution simple

Convertis le `.html` en `.md` ou `.txt`.

### Option 1 — convertir en Markdown

Sur le VPS :

```bash
python3 - <<'PY'
from pathlib import Path
from bs4 import BeautifulSoup

src = Path("fichier.html")
dst = Path("fichier.md")

html = src.read_text(encoding="utf-8", errors="ignore")
soup = BeautifulSoup(html, "html.parser")

for tag in soup(["script", "style", "noscript"]):
 tag.decompose()

text = soup.get_text("\n")
lines = [line.strip() for line in text.splitlines()]
text = "\n".join(line for line in lines if line)

dst.write_text(text, encoding="utf-8")
print(f"OK -> {dst}")
PY
```

Puis tu uploades :

```txt
fichier.md
```

## Si tu veux garder plusieurs `.html`

Mets-les dans un `.zip` :

```bash
zip documents-html.zip *.html
```

Mais attention : si le système inspecte l’intérieur du zip et refuse quand même les `.html`, mieux vaut convertir en `.md`.

## Meilleure pratique Second Brain

Pour le Second Brain :

```txt
.html brut → raw/assets ou raw/web
version lisible → raw/docs/fichier.md
```

Donc tu gardes éventuellement l’HTML original en archive, mais tu donnes au pipeline une version `.md` ou `.txt`.
