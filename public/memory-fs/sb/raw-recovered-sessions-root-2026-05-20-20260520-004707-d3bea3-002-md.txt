# Ce que font les meilleurs systèmes multi-agents

## 1. Un superviseur central

Pattern vu partout : **Supervisor / Manager / Mission Control**.

Chez nous :

```text
Hermes / COO
```

Il ne fait pas tout. Il :
- reçoit les signaux
- classe
- crée les tâches
- assigne aux bons agents
- suit les statuts
- bloque si risque
- demande validation si nécessaire
- vérifie les preuves avant de marquer terminé

C’est le cerveau d’exécution.

---

## 2. Des agents spécialisés

Pattern : chaque agent a un rôle strict.

Chez nous :

```text
Soren → stratégie / vision / DA
Atlas → dev / SaaS / modules / Vercel
Mia → KB / Data OS / documentation / CRM interne
Hermes → COO / orchestration
```

Important : ils ne doivent pas tous réfléchir à tout.
