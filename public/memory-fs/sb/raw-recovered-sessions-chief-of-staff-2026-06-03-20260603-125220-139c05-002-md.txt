## Intégration Hermes

Il ne faut pas que Convex appelle Hermes comme une boîte noire sans suivi.

### Pattern propre

```text
Convex mission créée
→ Convex crée agentRun pending
→ action Convex appelle endpoint Hermes
→ Hermes prend missionId/runId
→ Hermes exécute
→ Hermes POST updates vers Convex
→ Convex met à jour runs/steps/actions/logs
```

### Endpoints à prévoir côté Data OS

```ts
POST /api/hermes/run
```

Lance une mission vers Hermes.

Payload :
```json
{
 "workspaceId": "...",
 "missionId": "...",
 "agentId": "...",
 "objective": "...",
 "context": "...",
 "mode": "propose"
}
```

```ts
POST /api/hermes/callback
```

Hermes renvoie :
```json
{
 "runId": "...",
 "status": "running|completed|failed",
 "step": {...},
 "output": "...",
 "actions": [...]
}
```
