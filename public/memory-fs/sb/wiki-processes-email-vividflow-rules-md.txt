# Règles email VividFlow

## Statut
Validé par Thomas — 2026-06-09

## Boîte agent
La boîte mail agent VividFlow est `hey@vividflow.co`.
Elle est utilisée pour les agents VividFlow, codes, invitations, comptes outils, notifications et échanges techniques.

## Nouveau fil email
Pour le premier email d’une discussion :

```text
Bonjour [prénom],

J’espère que tu vas bien.

Je te contacte pour...
```

La suite doit rester claire, humaine et professionnelle.

## Signature et expéditeur visible
Utiliser :

```text
Équipe VividFlow
```

“Équipe VividFlow” est accepté pour le nom visible d’expéditeur et/ou la signature.

La photo de profil du compte mail doit être le vrai logo VividFlow.

Ne pas utiliser “Hermes VividFlow” : ça sonne trop outil interne.

## Réponse dans un fil existant
Ne pas remettre “Bonjour” dans une réponse immédiate d’un fil déjà ouvert.

Exceptions :
- si la réponse est envoyée le lendemain ou plus tard, remettre une salutation ;
- si la réponse est envoyée le soir, utiliser “Bonsoir”.

## Ton
Ton attendu : humain, simple, professionnel, pas sec, pas robotique.
