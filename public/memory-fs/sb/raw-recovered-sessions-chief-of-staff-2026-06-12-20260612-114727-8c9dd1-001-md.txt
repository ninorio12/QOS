 - Slack n’affiche pas toujours les apps dans la sidebar automatiquement.
 - Il faut chercher dans `Apps` ou via la barre de recherche.

5. **L’app existe côté Slack Developer mais pas installée dans le workspace**
 - Être créée sur `api.slack.com/apps` ≠ visible/utilisable dans Slack.
 - Il faut installation workspace + bot token actif.

De mon côté, j’ai vérifié : les 5 profils ont bien `SLACK_APP_TOKEN` et `SLACK_BOT_TOKEN`.

Donc le souci est presque sûrement côté Slack UI/install :
**réinstaller chaque app + activer App Home + inviter les bots dans les channels.**
