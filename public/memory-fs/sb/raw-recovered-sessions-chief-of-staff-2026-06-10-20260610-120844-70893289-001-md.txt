## assistant — 2026-06-10T16:05:38.975347

Oui, faisable. Pour un **agent démo client sur WhatsApp Business**, je te recommande 2 options :

**Option rapide — démo / MVP**
- Utiliser **Wasender** ou un bridge WhatsApp Web type **Baileys / whatsapp-web.js**.
- Tu connectes ton WhatsApp Business via QR code.
- Hermes reçoit les messages entrants et répond comme agent.
- Rapide à montrer à des clients, mais moins “officiel” / plus fragile.

**Option propre — production client**
- Utiliser **WhatsApp Business Cloud API officielle Meta**.
- Plus stable, conforme, pro.
- Mais setup plus lourd : Meta Business Manager, numéro dédié, app, webhook, templates validés.

Pour ton cas — **agent démo pour clients** — je ferais simple :

1. Créer un profil Hermes dédié :
```bash
hermes profile create whatsapp_demo
```

2. Lui donner un rôle clair :
> “Tu es un agent démo WhatsApp pour montrer à des clients comment une IA peut répondre, qualifier, expliquer une offre et prendre des infos.”

3. Activer le gateway WhatsApp :
```bash
hermes --profile whatsapp_demo gateway setup
```

4. Choisir WhatsApp si dispo dans le setup, puis connecter via QR code.

5. Lancer :
```bash
hermes --profile whatsapp_demo gateway run
```

6. Tester avec ton numéro WhatsApp Business.

Mon conseil : **ne branche pas ça directement sur ton vrai WhatsApp principal avec tous tes clients**. 
Crée plutôt un **numéro WhatsApp Business de démo dédié**, sinon tu vas mélanger tests, prospects et vie réelle.

Si tu veux, je peux te préparer le **prompt exact de l’agent démo WhatsApp** pour qu’il vende bien l’effet “waouh” aux clients.
