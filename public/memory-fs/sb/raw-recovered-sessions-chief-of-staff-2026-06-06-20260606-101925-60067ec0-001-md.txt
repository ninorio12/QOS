## assistant — 2026-06-06T10:24:37.255502

CDP = **Chrome DevTools Protocol**.

En simple : c’est la “prise télécommande” de Chrome.

Ça permet à un agent de piloter un vrai navigateur comme si tu ouvrais les DevTools :

- ouvrir une URL ;
- cliquer ;
- taper ;
- prendre une capture ;
- lire le DOM ;
- voir les requêtes réseau ;
- récupérer cookies/session ;
- détecter erreurs console ;
- contrôler onglets, downloads, iframes, etc.

Différence clé :

- **Browser classique** : l’agent utilise un navigateur intégré.
- **CDP** : l’agent se branche sur un vrai Chrome contrôlable à distance.

Pour Instagram/Meta, CDP est utile parce qu’on peut réutiliser un navigateur déjà connecté, mais il faut le faire proprement : session dédiée, accès limité, pas de scraping bourrin.
