# Lead intake form VividFlow

## Règle

Le formulaire iClosed ne doit plus être orienté uniquement immobilier. Il doit rester scalable pour plusieurs niches sans enfermer le prospect dans une liste métier incomplète.

## Champs à garder

- Prénom
- Nom
- Email
- Téléphone

## Champs à ajouter

1. **Quel est le nom de votre entreprise ?**
   - Type : réponse courte
   - Obligatoire : oui

2. **Quelle est votre activité ?**
   - Type : réponse courte
   - Obligatoire : oui
   - Placeholder conseillé : `Ex. régie immobilière, fiduciaire, entreprise de services techniques…`

3. **Comment avez-vous entendu parler de VividFlow ?**
   - Type : sélection unique
   - Obligatoire : oui
   - Options : Recommandation, Publicité, LinkedIn, Google, Email reçu, Événement / réseau, Autre

Si le formulaire permet une condition après “Recommandation”, ajouter : **Qui vous a recommandé VividFlow ?** en réponse courte.

## À supprimer

Supprimer l’ancienne sélection limitée à l’immobilier : agence immobilière, agent immobilier, promoteur immobilier.

## Curation — 2026-06-12 — formulaire iClosed final
Sources : `raw/messages/20260612-130131_telegram-session_c6559154.md`, `raw/messages/20260612-133132_telegram-session_c6559154.md`.

Décision formulaire : garder le formulaire court. Si une question doit sauter, supprimer **“Quelle est votre activité ?”** et garder **“Quel est le nom de votre entreprise ?”**, car l’entreprise permet de retrouver l’activité avant l’appel.

Champs validés :
- nom de l’entreprise ;
- rôle dans l’entreprise, en version courte : Dirigeant / fondateur, Gérant / responsable, Responsable opérationnel, Responsable commercial / marketing, Responsable RH, Autre ;
- source : Recommandation, Publicité, Newsletter, LinkedIn, YouTube, Autre.

Ne pas ajouter “Qui vous a recommandé VividFlow ?” si iClosed ne permet pas une condition propre; le demander ensuite en message ou en call. Paramètres booking validés à viser : période 7 jours, préavis 3h ou 4h, double réservation bloquée, lundi-vendredi 09:00–21:00, samedi 08:00–13:00, dimanche fermé.
