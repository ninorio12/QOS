## Ce qui coûte côté IA

- GPT-5.5 / Codex
- Claude Code si on l’utilise
- tout autre modèle IA appelé pour coder/analyser

C’est là que tu payes des tokens IA.

## Ce qui ne coûte pas directement

- Créer un token GitHub
- Créer un token Vercel
- Créer un token Convex
- Me donner l’accès au repo
- Créer une branche
- Ouvrir une PR

Ça ne facture pas automatiquement.

## Les seuls autres coûts possibles

Pas des “tokens IA”, mais de l’infrastructure :

- **Vercel** : si on fait énormément de builds, previews, trafic
- **Convex** : si on consomme beaucoup de requêtes, stocka

## Étape 3 — Permissions

Dans **Repository permissions**, mets seulement :

- **Contents** : `Read and write`
- **Pull requests** : `Read and write`
- **Actions** : `Read-only`
- **Metadata** : `Read-only`

Ne touche pas aux permissions “Account”.
