## Limites actuelles

1. GBrain contient encore trop de raw Telegram dans le même corpus, ce qui pollue certains résultats.
2. Embedding complet impossible avec all-minilm sur les grosses pages.
3. Data OS est fonctionnel mais encore léger : peu de tâches/clients/calls réels.
4. Les agents en RAM peuvent nécessiter restart/reset pour recharger les nouvelles mémoires/skills.

## Prochaine étape pour vraie machine de guerre

1. Séparer GBrain en deux modes :
   - runtime curated : wiki/runtime + docs/agents + Data OS docs
   - archive raw : raw Telegram consultable uniquement si nécessaire

2. Ajouter un cron/heartbeat :
   - importer wiki/runtime + Data OS docs
   - embed les pages courtes
   - tester query context-loader-core
   - écrire un rapport santé

3. Faire écrire chaque décision importante dans Second Brain ou Data OS au lieu de Telegram.

4. Ajouter une commande agent standard :
   - charger context-loader-core
   - charger agent-roles-core
   - charger source-of-truth-core
   - puis seulement répondre.
