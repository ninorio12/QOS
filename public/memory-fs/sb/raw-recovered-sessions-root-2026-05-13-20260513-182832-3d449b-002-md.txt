## C’est quoi GBrain ?

GBrain est un **second brain local** pour VividFlow/Cockpit.

Concrètement, c’est une base de connaissance durable où on peut stocker, structurer et retrouver :

- décisions importantes
- idées business
- concepts produit
- notes de meetings
- infos sur des personnes
- concurrents
- recherches marché
- apprentissages techniques
- mémoire stratégique de VividFlow

Ce n’est pas juste un dossier de notes. GBrain ajoute une couche intelligente :

- recherche dans les notes
- indexation
- liens entre concepts
- tags
- historique
- import de fichiers Markdown
- futur usage par agents IA

---

## Pourquoi c’est utile pour VividFlow

Aujourd’hui, Hermes a déjà une mémoire courte/longue, mais elle est limitée et doit rester compacte.

GBrain sert à stocker le **contexte lourd**.

Exemples :

### 1. Décisions produit

Au lieu de répéter 15 fois :

> VividFlow n’est pas un chatbot WhatsApp, c’est un OS agentique pour agences immobilières suisses.

On peut l’avoir dans GBrain comme doctrine produit.

---

### 2. Notes de stratégie

Exemples :

- positionnement VividFlow
- pricing
- concurrents
- persona agences immobilières
- objections commerciales
- architecture technique
- roadmaps

# Comment l’utiliser à bon escient

## 1. À utiliser pour les infos durables

Bonne utilisation :

- “Note cette décision : VividFlow doit prioriser les conversations avant les dashboards.”
- “Ajoute ça à la doctrine produit.”
- “Garde cette analyse concurrentielle.”
- “Crée une fiche sur ce prospect/agence.”
- “Sauvegarde ce raisonnement d’architecture.”
- “Retrouve-moi ce qu’on avait dit sur le CRM agentique.”

Mauvaise utilisation :

- tâches temporaires
- todo du jour
- infos périmées
- messages émotionnels sans valeur long terme
- données sensibles brutes
- mots de passe / tokens / secrets

---

## 2. Différence entre mémoire Hermes et GBrain

**Mémoire Hermes** = faits courts, très importants, injectés souvent.

Exemple :

```txt
Thomas a autorité complète sur VividFlow.
```

**GBrain** = connaissances longues, structurées, consultables.

Exemple :

```txt
Analyse complète du positionnement VividFlow sur le marché immobilier suisse.
```

Donc règle simple :

- Si c’est une préférence permanente courte → mémoire Hermes
- Si c’est une réflexion, une décision ou un document → GBrain
