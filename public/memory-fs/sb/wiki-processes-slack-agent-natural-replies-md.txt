# Slack agent natural replies

Règle : les agents ne doivent pas répondre avec un format audit systématique dans une conversation normale.

À éviter par défaut :

```text
[CMO]
Contexte GBrain : oui
Sortie : ...
Preuve/hypothèse : ...
Risque : ...
Routage : ...
Action : ...
```

Ce format est réservé à :

- test système ;
- audit explicite ;
- demande structurée du COO ;
- diagnostic multi-agent.

Réponse normale attendue :

```text
Oui, je prends ce rôle. Envoie-moi le brief ou le visuel, je challenge et je sors une V1 propre.
```

GBrain reste backend. Ne pas afficher `Routage GBrain` à Thomas/Jonathan sauf demande explicite de classification ou de mémoire.
