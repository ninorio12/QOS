Oui. Pour cette chaîne, il faut **séparer les rôles**, sinon ça produit du mauvais scraping et des imports sales.

Le workflow propre :

1. **Data Analyst**
 - Mission : trouver les leads.
 - Sources : local.ch, Google Maps, sites officiels, annuaires métiers.
 - Interdit : importer directement dans Data OS.
 - Accès outils :
 - Browser Use Cloud / Playwright
 - web search
 - Google Sheets en écriture
 - éventuellement Apollo en enrichissement, pas source principale

2. **Coordinateur**
 - Mission : contrôler la qualité avant import.
 - Il vérifie :
 - entreprise réelle
 - décideur nominatif
 - rôle cohérent
 - email professionnel vérifiable
 - source URL présente
 - pas de doublon
 - niche correcte
 - Il marque :
 - Qualité A : importable
 - Qualité B : importable si contact assez fiable
 - Qualité C : rejeté
 - Accès outils :
 - Google Sheets
 - Data OS lecture
 - web search / Browser Use si vérification nécessaire

3. **Agent Operations**
 - Mission : exécuter après validation.
 - Actions :
 - importer les leads A/B dans Data OS
 - créer les cartes prospection
 - préparer ou envoyer les emails selon validation
 - mettre à jour le statut dans le Sheet
 - Accès outils :
 - Google Sheets écriture
 - Data OS écriture
 - Gmail Clara / Workspace
 - Drive templates

4. **Agent KB**
 - Mission : documenter et stabiliser le process.
 - Actions :
 - maintenir la SOP scraping
 - garder les critères qualité
 - enregistrer les erreurs récurrentes
 - améliorer la fiche R&R des agents
 - Accès outils :
 - Second Brain / GBrain
 - Data OS Process/SOP
 - Google Drive docs si besoin

5. **Agent Debug**
 - Mission : intervenir si le scraping, l’import, Gmail ou Data OS casse.
 - Accès outils :
 - logs
 - terminal
 - repo/scripts
 - Browser Use / Playwright si bug scraping

Règle importante : **l’email ne doit pas partir automatiquement dès scraping**.

La bonne séquence est :

Scrape → Sheet → QA Coordinateur → Import Data OS → Email préparé → validation ou règle d’envoi claire → envoi → statut mis à jour.

Colonnes Sheet minimales :

- société
- site web
- niche
- ville / canton
- décisionnaire
- rôle
- email
- téléphone pro
- source société
- source décisionnaire
- source email
- score qualité
- décision QA
- statut Data OS
- statut email
- notes

Et la règle dure : **pas de décideur nominatif + source fiable = pas d’import**.

Pour moi, la répartition idéale est donc :

- Data Analyst = trouve
- Coordinateur = juge
- Operations = importe et envoie
- KB = fixe le process
- Debug = répare la machine

C’est ça qui évite que “remplir un Sheet” devienne du bruit commercial inutilisable.
