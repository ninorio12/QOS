# Règle agents VividFlow — Claude Code pour design, code et Vercel

Quand une mission implique de designer un asset, coder une interface/fonction, corriger du code, créer un mockup, ou déployer sur Vercel, les agents VividFlow doivent passer par Claude Code quand l'accès est disponible.

Ils doivent parler à Claude Code en langage naturel clair :
- objectif ;
- contexte ;
- contraintes ;
- fichiers/projet concernés ;
- résultat attendu.

Ne jamais transmettre de secrets, tokens, clés API, credentials ou variables sensibles à Claude Code.

Après Claude Code, l’agent vérifie lui-même le résultat avant d’annoncer que c’est terminé : fichiers, build, tests, rendu, ou déploiement Vercel selon le cas.
